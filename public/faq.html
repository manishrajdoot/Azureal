Frequently Asked Questions (FAQ)

What is Azureal?

Azureal is a real-time audio chat application built using WebRTC and Socket.IO. It allows users to stream audio between two clients with a modern interface.

How do I use Azureal?

Open two browser tabs or devices, navigate to the app URL, and click "Connect & Start Audio" in both. Allow microphone access, and you can start chatting!

Why isn't audio streaming?

Ensure both clients are connected, microphone access is granted, and you're using a browser that supports WebRTC (e.g., Chrome, Firefox).

Does Azureal work on mobile?

Yes, Azureal is responsive and works on mobile devices. However, ensure you're using a secure connection (HTTPS) and a compatible browser.

Can I use Azureal without HTTPS?

For local development, you can use `http://localhost`. In production, WebRTC requires HTTPS for security reasons.
